PART 6: Mini-Project
I created a mock fashion inventory chatbot for a fictional clothing boutique. The chatbot helps customers check whether fashion items such as heels, dresses, handbags, and jackets are available. The project uses two Python classes. The FashionInventory class stores and looks up item availability, while the FashionHelper class manages customer messages and conversation history. The program runs from my_main.py. The chatbot uses simple keyword rules to respond to customers. Purchase and return requests are referred to a store associate because the chatbot cannot process transactions.

I updated my fashion chatbot, Stella, to use Ollama for questions that are not covered by its rules. During testing, Stella correctly answered a question about store hours using the facts provided in its instructions. When asked about shipping costs, the model could not provide a confirmed answer and suggested contacting a store associate. I decided to keep inventory checks in code because stock information should come directly from the inventory tool instead of being generated by AI. I also kept purchase and return requests in code because these actions require a human store associate. This approach allows Stella to answer general questions while keeping important business rules predictable.py

I upgraded my Stella fashion chatbot so the model can decide when to check inventory or request an item reservation. The toolbox also refused a reservation request when the model supplied a customer name that the user never provided, preventing an unauthorized request.
